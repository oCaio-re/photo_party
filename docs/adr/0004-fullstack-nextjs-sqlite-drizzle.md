# Unified Fullstack Architecture with Next.js, SQLite, and Drizzle ORM

The application will be built as a unified fullstack TypeScript application using Next.js (App Router), Tailwind CSS, and SQLite with Drizzle ORM. This avoids maintaining separate frontend and backend deployments, eliminates the friction and cost of provisioning external cloud databases for development and initial deployment, and provides portable single-file persistence while leaving a clean path to migrate to PostgreSQL or distributed LibSQL if needed.
