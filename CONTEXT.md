# Photo Party

A platform for guests to upload and view photos in real time during an event via table QR codes.

## Language

**Event**:
A specific celebration or gathering where photo sharing takes place.
_Avoid_: Party, session, room

**Host**:
The organizer who creates an Event and manages its settings and photo exports.
_Avoid_: Admin, owner, creator

**Host Key**:
A private secret token granting administrative control over an Event.
_Avoid_: Password, API key, admin token

**Guest**:
An attendee at an Event who uploads or views photos.
_Avoid_: User, client, visitor

**Photo**:
An image uploaded by a Guest during an Event, optionally accompanied by an author name and dedication message.
_Avoid_: Post, upload, snap, submission

**Live Gallery**:
A shared real-time view of all photos uploaded by Guests during an Event.
_Avoid_: Feed, photostream, album

**Live Slideshow**:
A full-screen automated display mode that streams Event photos sequentially for venue screens or projectors.
_Avoid_: TV mode, projector view, screen saver

**Table**:
A designated seating area at an Event that identifies where photos originate.
_Avoid_: Seat, station, zone

**Upload Window**:
The operational period during which an Event accepts new Photos, constrained by an expiration timestamp and manually toggleable by the Host.
_Avoid_: Submission deadline, event timer

**Moderation Policy**:
The configuration governing whether uploaded photos appear immediately in the Live Gallery or require Host approval.
_Avoid_: Curation mode, review filter

**Photo Bundle**:
A single downloadable archive containing all photos collected during an Event.
_Avoid_: Zip file, backup, dump
